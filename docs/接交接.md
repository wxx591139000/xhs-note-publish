### 它是什么

把 AI 融入日常工作的**辅助发布**工具：电脑端统一管理素材（标题/正文/标签/封面/多图），手机端打开固定网址一键复制文案，粘到 APP 里人工发布。

**核心理念：小红书有风控，不做 API 自动发布。** 工具只负责「素材组织好 + 一键复制 + 自动填草稿」，发布动作由人在 APP 内完成，最稳。闲鱼同理。

## 三、架构要点（一句话版）

```
电脑/手机浏览器 ──→ Flask app.py (0.0.0.0:8800) ──→ SQLite data/notes.db
                        │
                        ├─ templates/ desktop / mobile / login / send
                        ├─ static/ app.js · mobile.js · send.js · style.css
                        └─ CORS 白名单（纵横工作台 / xhs 域名 / file://）
                     ↑
        本机 cloudflared 隧道 xhs-tunnel → https://xhs.zhuanlu.xyz
```

- **排序是前端行为**：`/api/notes` 与 `/api/auto/notes`（AutoX.js 按 `position` 自动发布）**顺序必须保持原样**，改动后端排序会静默改变自动发布顺序。
- **`sortNotes()` 与 `stripImgSlots()` 在 `app.js` / `mobile.js` 各有一份** → 必须双端一致，由两个回归脚本守（48 组 / 14 组矩阵断言）。
- **图位标记 `[[图N]]` 是内部语法**：所有出站路径（复制文案 / 卡片显示 / 字数统计）必须先 `stripImgSlots()`，否则会漏到发布文案里。
