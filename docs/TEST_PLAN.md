## 已知测试缺口

- **AutoX.js 真机**：无法在开发环境跑（需安卓+小红书实机），选择器未实机验证，需用户 DRY_RUN + 真机微调
- **并发**：多用户同时操作未测（单用户工具）
- **大文件**：超过 10MB 上传限制的边界未测
- **iOS 手机端**：复制/下载在 iOS 浏览器表现未实测

## 建议回归

每次改动 `app.py` 后，至少跑一遍：登录 → 建笔记带图 → 发布 → 自动化拉取 → 公网访问。
