# 小红书笔记发布工具 · 项目目标 SPEC

> 版本：v1.6.1（2026-10-01 二次归档）

## 项目定位

把 AI 融入日常工作——电脑端统一管理小红书笔记素材，手机端「辅助发布」到小红书 APP。参考生财有术文章《把 AI 融入日常工作，随手做出一个小红书笔记发布工具》。

**核心理念**：小红书有风控，**不做 API 自动发布**。工具负责把素材组织好、一键复制、自动填草稿，发布动作由用户在小红书 APP 内完成，最稳。

## 技术栈与架构概览

- **后端**：Python Flask 3.x + SQLite（`sqlite3` 标准库，无 ORM）
- **前端**：原生 HTML/CSS/JS，**无外部 CDN 依赖**（内网/隧道可离线用）
- **二维码**：Python `qrcode`
- **自动化**：AutoX.js（安卓无障碍服务）
- **部署**：本地 Windows 跑 Flask + cloudflared 新隧道 `xhs-tunnel`（27da88b4）

## 关键接口

- 页面：`/login`、`/app`（桌面）、`/m`（手机）、`/send`（发货话术，v1.6.0）
- 笔记：`GET/POST /api/notes`、`PUT/DELETE /api/notes/<id>`、`POST /api/notes/<id>/publish|revert`
- 上传：`POST /api/upload`、静态 `GET /uploads/<file>`
- 设置：`PUT /api/settings`（密码）
- 自动化：`GET/POST /api/auto/token`、`GET /api/auto/notes?token=`、`POST /api/auto/notes/<id>/drafted?token=`、`GET /xhs_auto.js`
- 只读（免登录，token 鉴权，供纵横工作台）：`GET /api/view/notes`、`GET /api/view/notes/<id>`（v1.6.0）
- 二维码：`GET /api/qr`

**跨域**（v1.6.0）：`after_request` 为白名单来源回 `Access-Control-Allow-*` 头。
白名单 = `null`（`file://`）、`https://zongheng.zhuanlu.xyz`、`https://xhs.zhuanlu.xyz`，另放行 `http://localhost*` / `http://127.0.0.1*`。

## 已知约束与边界

- 图片进小红书必须「先存相册再选」，浏览器无法把多图粘进小红书（平台硬限制）
- 手机浏览器**批量下载会被拦截/弹窗闪烁**，图片下载必须「逐张确认」（用户亲手触发）才稳定
- 手机浏览器会**缓存静态 JS**，改代码后需带版本号强制刷新，否则旧逻辑不生效
- iOS 无无障碍自动化，自动填充仅安卓可用
- 小红书 UI 改版会导致 AutoX.js 选择器失效，需按版本微调
- 闲鱼（淘宝系）自动发布风控更严，仅手动复制 + 用途标记，不做 API 自动发布
- 自动操作有被小红书设备指纹识别风险，建议低频率 + 存草稿人工审核
- 素材和 DB 存本机，电脑关机/隧道断开时手机无法访问
- **改模板必须重启服务**：`templates/*.html` 是 Flask 模板（非 debug 下内存缓存），改了不重启不生效；`static/*` 是静态文件，加 `?v=` 版本号刷新即可
- **图位标记 `[[图N]]` 是内部排版语法**：桌面/手机所有「复制文案」「卡片显示」「字数统计」都必须先 `stripImgSlots()` 剥离，否则标记会漏到小红书/闲鱼/公众号
- **排序是前端行为**：`/api/notes` 与 `/api/auto/notes`（按 `position` 自动发布）顺序**不变**，避免动后端 SQL 造成自动化回归
- **老笔记没有图位数据**：`body` 里原本零 `[[图N]]`，预览走「末尾兜底 + 未指定位置提示」；要按策划位置排布需补标记
- ★ **`/api/notes` 的 `images`/`cover` 是「裸哈希文件名」**（不含路径）：**每一处渲染都得自己拼 `/uploads/` 前缀**。漏一处就会 404，且该 `<img>` 的 `onerror` 会兜底成占位图 ⇒ **看着"有图"，肉眼与元素计数都判不出来**（v1.6.1 真实事故，见 `PITFALLS.md`）
- ★ **静态文件与模板的缓存行为不同**：`static/*` 实时读盘（改完刷新即生效）；`templates/*.html` 内存缓存（**必须重启**）。别把"重启"当唯一手段，也别指望改模板即时生效
- **`/login` 是表单页，不是 JSON API**（**无** `/api/login`）：探测时误用会得 404，勿据此判"服务异常"
